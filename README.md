# Grécko 2026

Mobilná PWA pre 14-dňový road trip severným Gréckom.

## Funkcie

- interaktívna dotyková mapa s pinch-to-zoom a posúvaním
- výber dní 1–14 a filtre nocľahov/aktivít
- podrobný itinerár s odkazmi do Google Maps
- dátum začiatku cesty uložený lokálne v telefóne
- offline cache po prvom načítaní
- inštalácia na plochu iPhonu cez Safari

## GitHub Pages

Publikačný priečinok je `docs/`. V repozitári nastavte **Settings → Pages → Deploy from a branch → main → /docs**.
